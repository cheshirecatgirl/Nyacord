Profiles

Separate browser sessions. Profiles cannot see each other.

    New profile

    Encrypts every profile's session data — cookies, local storage, cache, and the token Discord keeps there — into a single sealed file when you quit. The key is derived from your passphrase and exists only while the app is open.

    Set a passphrase

    A sealed file can be guessed at offline, with no app in the way, so length is what protects it. Use a phrase, not a PIN.

    There is no recovery. Nyacord never stores your passphrase, so nobody — including us — can reset it. Forgetting it means the profile data is gone.

    Auto-lock

    Shows the lock screen after the machine has been idle this long. Locking hides everything and drops the key; it does not re-seal the files, which happens when you quit.

    Change passphrase

    Turn the vault off

    Leaves your profile data readable on disk. Only possible while it is open.

    Proxy for

    Set per profile, so one identity can leave over Tor or a VPN while another leaves directly.

    Secure DNS

    Hides which hosts you contact from whoever runs your network. Applies to every profile.
